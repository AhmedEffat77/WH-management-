## 🆘 Troubleshooting Quick Guide

### Issue: "Can't download files"
**Solution:** Follow [DOWNLOAD_GUIDE.md](DOWNLOAD_GUIDE.md) step-by-step

### Issue: "Files won't open in browser"
**Solution:** 
- Make sure files have correct extensions (.html, .js)
- Don't add extra .txt extensions
- Open in modern browser (Chrome, Firefox, Edge)

### Issue: "Login not working"
**Solution:**
- Check browser console (F12)
- Verify `js/auth.js` is in correct location
- Use exact credentials: `admin` / `admin123`

### Issue: "Deployment failed"
**Solution:**
- Verify all files are uploaded
- Check folder structure is correct
- Wait 2-3 minutes for deployment to complete

### Issue: "Access denied after deployment"
**Solution:**
- Make sure you're using the UPDATED `auth.js` (with demo users)
- Clear browser cache
- Try in incognito/private mode
