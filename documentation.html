How to Download Files from GenSpark

Important: You need to download files manually from GenSpark interface

Method 1: Copy-Paste Each File

  1. In GenSpark, open the file you want to download
  2. Select all content (Ctrl+A or Cmd+A)
  3. Copy (Ctrl+C or Cmd+C)
  4. Open a text editor on your PC (Notepad, VS Code, etc.)
  5. Paste (Ctrl+V or Cmd+V)
  6. Save with the correct filename and extension (.html or .js)
  7. Make sure to save JS files in the js/ subfolder

Method 2: Use GenSpark Download Feature (if available)

  1. Look for a "Download" or "Export" button in GenSpark
  2. Download as ZIP file
  3. Extract to your computer
  4. Verify all files are present

Troubleshooting

❌ "Access Denied" Error

Solution: Already fixed! Make sure you're using the updated auth.js file.

  • Download the latest auth.js file
  • Clear browser cache
  • Try in incognito/private mode

⚠️ Login Not Working

Solution: Check file structure and credentials

  • Verify auth.js is in the js/ folder
  • Use exact credentials: admin / admin123
  • Check browser console for errors (F12)

ℹ️ Files Won't Upload to Hosting

Solution: Verify file structure and format

  • Make sure all files have correct extensions (.html, .js)
  • Keep the js/ subfolder structure
  • Upload entire folder, not individual files
