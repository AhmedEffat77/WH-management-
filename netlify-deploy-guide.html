Prepare Your Files

Before You Start

Verify that you have ALL files in the correct structure on your computer.

Required Folder Structure:

warehouse-system/          ← Main folder (you can name it anything)
├── index.html
├── admin-dashboard.html
├── warehouse-dashboard.html
├── technical-dashboard.html
├── user-dashboard.html
├── start-here.html
├── documentation.html
└── js/                    ← JavaScript subfolder (MUST be named "js")
    ├── auth.js
    ├── user-dashboard.js
    ├── warehouse-dashboard.js
    └── technical-dashboard.js

Important!

  • • The js/ folder MUST exist and be named exactly "js"
  • • All JavaScript files MUST be inside the js/ folder
  • • HTML files MUST be in the main folder (not in subfolders)
  • • File names are case-sensitive on some systems

Quick Verification:

  1. Open your main folder (warehouse-system)
  2. You should see 7 HTML files directly in this folder
  3. You should see 1 subfolder named "js"
  4. Inside js/ folder, you should see 4 JavaScript files
  5. Double-click index.html - it should open in browser and show login page

Netlify Dashboard

Look for "Add new site" or "Deploy manually" button

Two Ways to Deploy:

Method 1: Drag & Drop (EASIEST)
  1. Look for the "Deploy manually" section on the dashboard
  2. You'll see a large area that says "Drag and drop your site output folder here"
  3. This is where you'll drag your warehouse-system folder
  4. Skip to Step 5 below
Method 2: Add New Site Button
  1. Click the "Add new site" button (usually top right)
  2. Select "Deploy manually" from the dropdown
  3. You'll see the drag & drop area
  4. Continue to Step 5 below

Can't find the button? Look for: "Sites" in the menu, then "Add new site", or scroll down to see the drag & drop area.

    Click "Site settings" button on your site page

  2. Find "Site information"

Troubleshooting Common Issues

❌ Problem: "Page not found" or 404 error

Solution:

  • Make sure you uploaded the FOLDER, not just files
  • Verify index.html is in the root (not in a subfolder)
  • Wait 2-3 minutes for deployment to fully complete
  • Try accessing: yoursite.netlify.app/index.html

⚠️ Problem: Login doesn't work

Solution:

  • Verify js/auth.js file was uploaded
  • Check browser console for errors (press F12)
  • Make sure you're using the updated auth.js with demo users
  • Try clearing browser cache
  • Test in incognito/private browsing mode

ℹ️ Problem: Upload failed or stuck

Solution:

  • Check your internet connection
  • Try refreshing the Netlify page
  • Make sure folder size is reasonable (should be under 10MB)
  • Try using "browse to upload" instead of drag & drop
  • Close other browser tabs to free up memory

🔧 Problem: CSS/styling not working

Solution:

  • Styles are loaded from CDN (internet required)
  • Check if Tailwind CSS CDN is accessible
  • Clear browser cache and reload
  • Check browser console for CDN loading errors
